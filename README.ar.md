# NABD AI — نبض

منصة تعمل على جهازك لمراقبة حسابات **Telegram** وتحليل رسائلها بالذكاء الاصطناعي: تربط حساباتك، تختار المجموعات والقنوات التي تريد مراقبتها، تصف بكلماتك ما الذي تبحث عنه، فتظهر لك **بطاقات مباشرة** مع تنبيهات وتحليلات وتقارير وسجل عمليات كامل.

## ما الذي تحتاجه
- هاتف أندرويد (يفضّل ذاكرة 3 GB فأكثر ومساحة حرة 1.5 GB).
- تطبيق **Termux** من **F-Droid** أو من GitHub Releases (نسخة Google Play قديمة ولا تعمل).
- حساب Telegram + **API ID / API Hash** (من my.telegram.org).
- مفتاح مزود ذكاء اصطناعي (اختياري: Gemini أو OpenAI أو Anthropic أو Grok (xAI)، أو نموذج محلي). بدونه يعمل النظام بالكلمات المفتاحية فقط.

## التشغيل على Termux — خطوة بخطوة
```bash
# 1) تحديث Termux وتثبيت unzip
pkg update -y && pkg upgrade -y && pkg install -y unzip

# 2) انقل nabd-ai.zip إلى Termux (مرة واحدة تُعطي Termux صلاحية التخزين)
termux-setup-storage
cp ~/storage/downloads/nabd-ai.zip ~/

# 3) فك الضغط وشغّل الإعداد (يثبّت nodejs و postgresql و redis، وينشئ قاعدة البيانات و .env بمفاتيح عشوائية)
cd ~ && unzip nabd-ai.zip && cd nabd-ai
bash scripts/termux-setup.sh

# 4) التشغيل (PostgreSQL + Redis + الخادم + العمّال، مع إعادة تشغيل تلقائية عند أي انهيار)
bash scripts/start.sh
```
ثم افتح المتصفح على: **http://127.0.0.1:8080**

### أول مرة: معالج الإعداد (7 خطوات)
1. إنشاء حساب المدير ← 2. فحص قاعدة البيانات ← 3. فحص Redis ← 4. مزود الذكاء الاصطناعي (يمكن تخطيه) ← 5. إضافة حساب Telegram (رقم الهاتف + API ID + API Hash ثم الكود وكلمة مرور التحقق بخطوتين إن وُجدت) ← 6. إنشاء أول رادار (اكتب وصفًا بالعربية، راجع الإشارات المقترحة، ثم **تأكيد وتفعيل**) ← 7. تشغيل العمّال ← **NABD AI جاهز**.

بعد إضافة الحساب وتوصيله، تُفعّل مراقبة كل المجموعات والقنوات الفائقة التي ينتمي إليها الحساب تلقائياً، ويُعاد تفعيلها عند المزامنة. لا ينضم النظام إلى أي مجموعة؛ بل يراقب فقط المحادثات التي يستطيع الحساب الوصول إليها. تتبع القنوات والمحادثات الأخرى إعداد «مراقبة المصادر الجديدة». افتح **البث المباشر** وسترى المطابقات لحظة وصولها.

### إبقاء الخدمة تعمل في الخلفية
- `start.sh` يفعّل **wake-lock** تلقائيًا (إشعار Termux الدائم يعني أنه يعمل).
- أوقف **توفير البطارية** لـ Termux: الإعدادات ← التطبيقات ← Termux ← البطارية ← "بدون قيود".
- للتشغيل بعد إعادة تشغيل الهاتف: ثبّت **Termux:Boot** وأنشئ الملف `~/.termux/boot/nabd` يحتوي:
  ```bash
  #!/data/data/com.termux/files/usr/bin/bash
  cd ~/nabd-ai && bash scripts/start.sh
  ```
- لتوفير الذاكرة على هاتف ضعيف ضع في `.env`: `EMBED_WORKER=true` (يشغّل العمّال داخل عملية الخادم).

### أوامر مفيدة
| الأمر | الوظيفة |
|---|---|
| `bash scripts/status.sh` | حالة PostgreSQL و Redis والخادم والعمّال |
| `bash scripts/logs.sh api` | سجل الخادم (`worker` / `postgres` / `redis` أيضًا) |
| `bash scripts/stop.sh` | إيقاف الخادم والعمّال (`--all` لإيقاف PostgreSQL و Redis أيضًا) |
| `node scripts/create-admin.js admin 'كلمة-سر-جديدة1'` | إنشاء/استعادة حساب المدير |
| `npm test` | تشغيل الاختبارات (يحتاج PostgreSQL و Redis) |

### الوصول من جهاز آخر على نفس الشبكة
غيّر في `.env`: `HOST=0.0.0.0` ثم أعد التشغيل. **تحذير:** لا تعرّض اللوحة للإنترنت بلا HTTPS (استخدم Cloudflare Tunnel أو nginx مع شهادة) وفعّل `COOKIE_SECURE=true` و `TRUST_PROXY=true`.

### النسخ الاحتياطي والتحديث
- **انسخ سطر `MASTER_KEY` من ملف `.env` إلى مكان آمن.** بدونه لا يمكن فك تشفير الجلسات ومفاتيح الذكاء الاصطناعي والنسخ الاحتياطية.
- النسخ الاحتياطية (قاعدة البيانات/الإعدادات/القواعد) من **النظام ← النسخ الاحتياطية** وتُحفظ مشفّرة في `data/backups`.
- التحديث: أوقف الخدمة، فك ضغط النسخة الجديدة فوق المجلد (لا تحذف `.env` ولا `data/`)، نفّذ `npm ci --omit=dev --ignore-scripts` ثم `bash scripts/start.sh` (الترقيات تُطبَّق تلقائيًا).

## الحصول على API ID و API Hash
ادخل إلى https://my.telegram.org بحساب Telegram الذي ستستخدمه ← **API development tools** ← أنشئ تطبيقًا ← انسخ `api_id` (رقم) و `api_hash` (32 حرفًا). تُخزَّن مشفّرة ولا تُعرض مرة أخرى.

## حل المشاكل الشائعة
| المشكلة | الحل |
|---|---|
| `لا توجد عملية Worker تعمل` | نفّذ `bash scripts/start.sh` |
| PostgreSQL لا يبدأ | `bash scripts/logs.sh postgres`؛ ثم `bash scripts/stop.sh --all` وأعد التشغيل؛ تأكد أن `data/pgdata` داخل مجلد Termux وليس على `/sdcard` |
| الكود لا يصل من Telegram | يصل عادةً داخل تطبيق Telegram نفسه (وليس SMS)؛ تأكد أن API ID/Hash تخص نفس الحساب |
| حساب يظهر "غير متصل" | افتح صفحة الحسابات واقرأ آخر خطأ؛ **إعادة الاتصال** تصفّر العدّاد؛ إن كانت الحالة `auth_required` أضف الحساب من جديد |
| بطاقات تحمل "وضع مبسّط: كلمات فقط" | مزود الذكاء الاصطناعي لا يعمل: افتح **إعدادات الذكاء الاصطناعي ← اختبار** |
| خطأ أثناء `npm` على Termux | استخدم `--ignore-scripts` (السكربت يفعل ذلك تلقائيًا) |

## ما الذي تم اختباره وما الذي لم يُختبر
**اختُبر آليًا:** 46 اختبارًا (وحدات، واجهة برمجية، قاعدة بيانات، عمّال، ذكاء اصطناعي، أمان، سيناريوهات الأعطال: سقوط Redis وPostgreSQL والذكاء الاصطناعي وإعادة التشغيل وانقطاع الاتصال)، وتجربة كاملة للواجهة بمتصفح حقيقي (عربي/إنجليزي/جوال)، وتثبيت نظيف من الملف المضغوط بنفس سكربتات Termux.
**لم يُختبر في بيئة البناء:** الاتصال الفعلي بخوادم Telegram (لا توجد بيانات اعتماد/شبكة)، وهاتف أندرويد حقيقي، و`docker compose`، وإرسال البريد عبر SMTP، ومزودي الذكاء الاصطناعي الحقيقيين. لذلك جرّب أول مرة بحساب ثانوي، وراجع [`docs/COVERAGE.md`](docs/COVERAGE.md) للتفاصيل.

## مزودات الذكاء الاصطناعي

| المزود | متطلبات الإعداد | العنوان الافتراضي |
|---|---|---|
| Grok (xAI) | مفتاح API من [console.x.ai](https://console.x.ai) | `https://api.x.ai/v1` (النموذج الافتراضي `grok-4-fast`) |
| Gemini / OpenAI / Anthropic | مفتاح API من المزود | يُضبط تلقائيًا |
| نموذج محلي | عنوان خادم متوافق مع OpenAI | مثل `http://127.0.0.1:11434/v1` |

## استخدام مسؤول
استخدم فقط حسابات ومحادثات يحق لك الوصول إليها، والتزم بشروط Telegram وقوانين الخصوصية في بلدك. لا يتضمن النظام أي ميزة لجمع الأعضاء أو الانضمام التلقائي أو إرسال رسائل تلقائية أو تجاوز حدود Telegram.
