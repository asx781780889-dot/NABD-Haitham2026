# نظام كشف المعلنين (NABD)

## النطاق
يضيف النظام طبقة مستقلة لكشف الحسابات التي تنشر عروضًا أو إعلانات داخل البث المباشر، مع الحفاظ على مسار الرادارات الحالي. لا يستخدم أرقام الهاتف الخام في `ad_signals`؛ تُخزّن فقط أسماء الإشارات وأوزانها.

## طرق الكشف

1. **نقاط القواعد:** `src/engine/adscore.js` يطبع النص ويجمع إشارات رقم الهاتف والروابط واسم المستخدم وعبارات العرض والدعوة للسعر والبنية والوسائط، ويطرح إشارات طالب الخدمة والسؤال القصير. الناتج بين 0 و100 وقابل للاختبار دون قاعدة بيانات.
2. **سلوك المرسل:** `src/services/senders.js` يحفظ آخر 30 بصمة في Redis لكل مرسل، ويستخدم ذاكرة LRU محدودة عند تعذر Redis. يقيس التكرار والنشر في مجموعات مختلفة والاندفاع والتاريخ، مع idempotency حسب `messageId`.
3. **تصنيف الذكاء الاصطناعي:** يستدعى فقط للبطاقات وفي المنطقة الرمادية 30–70 وبحد 20 استدعاء في الدقيقة. الاستجابة محققة بـ Zod ومحصورة في `seeker | advertiser | other`، مع تخزين Redis لمدة 24 ساعة. تعطل AI لا يوقف خط المعالجة.
4. **ملف الحساب:** جدول `sender_profiles` يحتفظ بالحالة والدرجة والعدادات والنبذة والرايات المستقبلية. حالات المشغّل لا تُغيّر تلقائيًا، وتعود الحالات الآلية إلى `unknown` بعد 14 يومًا بلا إعلان ضمن التنظيف.
5. **تعلّم المشغّل:** `ad_examples` مستقل عن `feedback_examples`. تتوفر أزرار معلن/غير معلن على البطاقة، ومسارات معايرة وتصنيف يدوي، وصفحة `/advertisers` لإدارة الحالات.

## API

- `POST /api/ads/test` — معايرة نص وإرجاع الدرجة والإشارات ونتيجة AI إن توفرت.
- `GET /api/advertisers` — قائمة الحسابات المصنفة، للقراءة بدور `viewer`.
- `PATCH /api/advertisers/:id` — تعيين `unknown` أو `suspect` أو `advertiser` أو `trusted` بدور `operator`، مع تدقيق.
- `POST /api/ads/feedback` — حفظ مثال `ad` أو `not_ad` وتحديث البطاقة، بدور `operator`.
- `POST /api/ads/lexicon` — إضافة/تحديث عبارة القاموس، بدور `operator`، مع إبطال ذاكرة الإعدادات.

## الإعدادات

كل الإعدادات تبدأ بالبادئة `ads.` وتظهر من خلال صفحة الإعدادات الحالية: نافذة السلوك، عدد الإعلانات اللازم لتصنيف المرسل، أيام التلاشي، حدود المنطقة الرمادية، والحد الأقصى لاستدعاءات AI.

## الاختبار والتشغيل

```bash
npm run test:unit
npm test
node scripts/migrate.js
```

يجب تشغيل التكامل على قاعدة اختبار وRedis مخصصين؛ اختبارات المشروع الحالية تحذف schema وتفرغ Redis. لا تستخدم حسابات Telegram حقيقية، وتستخدم الاختبارات النقل الوهمي الموجود في `tests/helpers/fakes.js`.
